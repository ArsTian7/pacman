# 吃豆人 · Pac-Man

用原生 HTML / CSS / JavaScript 写的单文件吃豆人小游戏，零依赖、零构建，打开即玩。

## 在线游玩

https://ar7ian.github.io/pacman/

## 本地游玩

把 `index.html` 下载下来，双击用浏览器打开即可。

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 或 W A S D | 移动 |
| 空格 | 暂停 / 继续 |
| R | 重新开始 |
| M | 开关音效 |
| 手机滑动屏幕 | 控制方向 |

## 玩法

- 吃光所有豆子即过关；大颗的「能量豆」会让幽灵变蓝，此时可以反过来吃掉它们
- 连吃幽灵分数翻倍：200 → 400 → 800 → 1600
- 被幽灵碰到掉一条命，3 条命用完游戏结束
- 最高分存在浏览器本地（localStorage）
- 关卡越高，幽灵越快、蓝灯时间越短

## 幽灵 AI

- **Blinky（红）**：直接追着吃豆人跑
- **Pinky（粉）**：瞄准吃豆人前方 4 格
- **Inky（青）**：以 Blinky 为参照取对称点
- **Clyde（橙）**：距离 8 格以内会怂回角落

幽灵会在「分散 / 追击」两种状态间周期性切换。
